# 요건 정의서 — 토큰 통계·월별 공급사 사용 대조

## 개요

- **무엇을 하는 화면인가**: 토큰 실사용·귀속·계량 출처를 조회하고 공급사 월 대조값과 계획/실제 1M 비용 괴리·수동 보정 참고 근거을 확인한다.
- **프로세스상 위치**: 호출별 계량/추정·귀속 → 월 사용 대조 → 관리자 보정 선택/근거 → SCR-021의 미래 계획
- **이 데이터를 누가 쓰나**: 권한 있는 관리자와 연결 업무의 담당자가 현재 적용값 또는 업무 처리 근거로 사용한다.
- **바꾸면 어디가 흔들리나**: 소유 기능의 요청·권한·참조 및 이력/감사 연결을 함께 확인한다.

> 미구현 화면 초안이며 사용자 화면 합의·제품 구현·G3(설계 승인 게이트) 승인이 아니다. [화면 정본](../../../../spec/60-screens/_index.yaml)과 [기능 정본](../../../../spec/31-features/002-admin.yaml)을 따른다. 표시 예시는 실제 데이터·물리명·운영 기본값이 아니다.

## 1. 화면 구성

상단 조회조건 → 토큰 통계·월별 공급사 사용 대조 목록 → 호출별 사용 · 공급사 월 대조 · 보정 선택 · 산정·처리 근거 순서다. 제목·건수는 왼쪽, 작업 버튼은 상단·그리드 툴바·모달 하단에서 우측 정렬한다. 초기 화면의 모든 탭은 실제 전환하며 같은 상위 대상의 입력·선택·추가/제거 행을 유지한다.

### 1-3. 마스터-디테일·이력 경계

- 선택 변경·조회·이탈 때 미저장 변경을 확인하고 취소하면 선택·입력을 보존한다. 결과 불명에는 새 명령 없이 원 처리 결과를 확인한다.
- 업무 원장·로그의 자체 기록을 조회한다. 이 화면 자체를 관리 구성 이력으로 복제하지 않는다.
- 선택 월의 대조/보정 선택 근거만. 원 호출/실사용/배정은 읽기 전용

## 3. 조회 — 테이블과 범위

### 3-1. 사용 테이블 · 결합

| 테이블 | 역할 | 결합 기준 |
|---|---|---|
| 미정 — 논리: 토큰 통계·월별 공급사 사용 대조 | 소유 업무 기록/원장 | 안정 식별자 + 해당 조회 문맥. 물리 테이블·컬럼·조인/API는 소유 상세 설계 후속 |

### 3-2. 고정 조건 · 기본 정렬

- 항상 현재 메뉴·액션과 대상 열람 범위를 서버에서 검사한다. 선택한 업무 기록의 당시 내용과 현재 관측을 구분한다.
- 기본 정렬·페이지 방식·조회 기간/상한·보존 기간·대량 반출 한도는 소유 계약 미정이다. 운영값을 추정하지 않는다.
- 빈 결과·권한 제외·조회 실패·미확인을 구분한다. 명령과 연계 조회의 권한을 자동 승계하지 않는다.

## 6. 규칙 — 저장 · 실행

사용자별/월별 상세는 SCR-066·SCR-067이 같은 원 집계/근거를 조회한다. 월말 최종 배분은 FEAT-045가 다음 달 기준으로 수행하며 이 종합 화면에서 기준·등급·배정 결과를 직접 바꾸지 않는다. 이전 예정 생성본을 중복 배정으로 합산하지 않는다.

계획 USD 단가와 실제 비용의 괴리는 동일 통화·사용자/시스템 귀속·계량 범위로 맞춘 뒤 비교한다. 비교에 사용한 환산 기준/근거를 남기며 미상/범위 불일치이면 비교 불가로 표시한다. 이 대조는 확정 월을 재환산하거나 단가/배정을 변경하는 동작이 아니다.
