# 사용자 그룹

> Hub에서 사용할 그룹의 이름과 설명을 등록하고 참조 연결 상태를 확인합니다.

**메뉴 위치** AI Agent Hub 관리 › 공통 기반 › 사용자 그룹

## 1. 먼저 알아 둘 것

현재는 그룹 정의를 관리합니다. 사용자 소속 편집과 지식·카탈로그·API·도구의 실제 목록은 각 원 소유 기능 연결 후 제공됩니다. 이 화면의 그룹은 관리자 역할이나 쿼터 등급과 별개입니다.

## 2. 찾기

1. 그룹명을 입력하거나 비워 둡니다.
2. [조회]를 누릅니다. 그룹명 부분 일치로 검색합니다.
3. 그룹을 선택하면 하단 탭에서 연결 상태와 전체 참조를 확인합니다. 조회가 끝나기 전에는 삭제할 수 없습니다. 신규 그룹은 먼저 저장해야 합니다.

## 3. 하기

### 3-1. 등록·수정하기

1. [행 추가]로 새 행을 만들거나 기존 행의 그룹명·설명을 편집합니다.
2. 그룹명은100자 이내로 입력하고 설명과 상단 변경 사유를 채웁니다.
3. [저장]에서 변경 건수를 확인합니다. 번호·등록/수정 정보는 서버가 기록합니다.
4. 일부 행만 실패하면 성공은 유지되고 실패한 행만 남습니다. 사유를 확인하고 고쳐 저장합니다.

### 3-2. 연결 상태 확인하기

사용자·지식·스키마 카탈로그·API·커스텀 도구 탭을 선택합니다. “원 소유 기능 연결 전입니다. 소속 편집과 자산 조회는 해당 기능 연결 후 제공됩니다.”는 연결 준비 상태입니다. 빈 결과나 사용하지 않는 그룹이라는 뜻이 아닙니다.

### 3-3. 삭제·내보내기

모든 소유자의 참조 없음이 확인된 그룹만 삭제 체크 후 저장할 수 있습니다. 상단 조회 직후에는 삭제가 잠겨 있습니다. 행 선택 후 모든 하단 탭 조회가 끝나고 참조 없음이 확인되면 삭제가 열립니다. 상세 탭이 연결 전이어도 관련 저장소 자체가 아직 설치되지 않은 경우에는 미참조로 확인할 수 있습니다. 남은 참조(비활성 포함), 설치된 저장소의 검사 기능 누락, 확인 실패는 삭제를 막으며 기존 관계를 자동 삭제하지 않습니다. 최종 저장 시 서버가 다시 확인합니다. 삭제 성공 시 직전 전체 이력은 보존합니다. 그룹 목록의 엑셀은 현재 조회된 페이지를 내보내며 자산 탭은 다운로드를 제공하지 않습니다.

## 4. 처리되지 않을 때

| 안내 | 할 일 |
|---|---|
| 변경 사유를 입력하세요. | 상단 사유를 입력합니다. |
| 기준 정보가 변경되었습니다. 다시 조회해 주세요. | 다른 관리자의 변경을 조회하고 다시 편집합니다. |
| 원 명령의 결과가 미확정입니다. 내용을 유지하고 저장을 다시 눌러 결과를 확인하세요. | 같은 관리자·같은 브라우저 탭에서 다시 저장합니다. 화면을 다시 열어도 원 명령을 복구합니다. 다른 브라우저에서 신규 행을 다시 만들지 않습니다. |
| 모든 소유자의 참조 없음이 확인돼야 삭제할 수 있습니다. | 연결 상태와 원 소유자의 남은 참조를 확인합니다. |

## 5. 변경 이력

그룹 정의의 현재값과 전체 이력·처리자·시각·사유는 함께 저장됩니다. 독립 이력 조회 화면은 후속 공통 이력 화면에서 제공합니다.
