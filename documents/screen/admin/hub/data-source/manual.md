# 데이터소스 관리

> 서버에서 등록한 조회 원천의 업무 설명·시각 체계·그룹·데이터 조회 가이드를 보완합니다.

**메뉴 위치** AI Agent Hub 관리 › 연동 관리 › 데이터소스

[데이터소스 전체 화면](./mockup.html#main)

## 1. 준비와 찾기

데이터소스의 등록과 별칭·연결은 운영 담당자가 서버 설정에서 관리합니다. 이 화면은 기존 데이터소스의 업무 메타를 보완합니다. 사용자 그룹은 사용자 그룹 메뉴에서 먼저 등록합니다.

별칭과 서버 설정 불일치 조건으로 [조회]하고 한 행을 선택합니다. 전체 편집본이 로드되면 해당 행의 DBMS 버전·DB·DW 유형·시각 체계·설명·데이터 기준 시각 정보를 수정할 수 있습니다. 서버가 아는 시간대만 선택하며 선택을 해제하면 미지정으로 저장합니다. 시간대 목록을 읽지 못하면 기존 선택을 유지합니다.

## 2. 업무 메타와 가이드 저장

1. 상단의 업무 메타를 보완합니다. DW 동기화 방식은 DW일 때 편집하는 참고 메모입니다. DB로 전환해도 기존 메모를 보존하며 배치나 실제 동기화 작업을 실행하지 않습니다.
2. [데이터 조회 가이드]에서 [행 추가]를 누르고 가이드 제목과 상세 설명을 입력합니다. 가이드는 여러 건을 작성할 수 있으며 각 제목과 본문은 필수입니다.
3. 상단 [저장]을 누르고 새 변경 사유를 입력합니다. 공백만 있는 사유로 저장할 수 없습니다.
4. 업무 메타·전체 그룹·전체 가이드를 함께 저장합니다. 성공 확인 뒤 목록에서 다시 선택해 반영된 전체 구성을 확인합니다.

[데이터 조회 가이드](./mockup.html#guides)

탭을 이동해도 입력은 보존됩니다. 저장 실패나 버전 충돌은 입력을 유지하며 일부 구성만 저장하지 않습니다. 응답을 받지 못한 경우 같은 원 명령으로 결과를 확인한 뒤 재시도하며 새 명령을 만들지 않습니다.

## 3. 적용 가능 그룹

[사용자 그룹]의 [그룹 추가]로 기존 그룹을 선택합니다. 새 매핑은 활성 상태로 시작합니다. 활성 여부를 바꾸거나 연결을 제거해도 상단 전체 저장 전에는 적용되지 않습니다. 하위 카탈로그에서 사용하는 그룹을 제거하거나 활성 하위 매핑이 있는 부모 그룹을 끄면 저장을 거부합니다. 적용 가능 그룹은 카탈로그의 매핑 후보이며 데이터베이스 전체 열람 권한을 주지 않습니다.

[사용자 그룹](./mockup.html#groups)

## 4. 사용처와 비교 결과

[사용 스키마 카탈로그]는 권한 범위의 사용처를 읽는 영역입니다. 현재 카탈로그 기능과의 실제 연결 전에는 사용처를 확인할 수 없다는 안내를 보여 줍니다. 참조가 없다는 뜻이 아닙니다.

[사용 스키마 카탈로그](./mockup.html#catalogs)

[컬럼 불일치]와 [인덱스 불일치]는 후속 카탈로그 구조 비교 기능이 제공할 결과입니다. 현재 결과를 확인할 수 없으면 0건이나 정상으로 표시하지 않습니다. SQL 지원도 확인 필요로 표시하며 가이드를 등록했다고 업무 SQL을 실행할 수 있는 것은 아닙니다.

## 5. 설정에서 제거된 데이터소스 정리

서버 설정에서 연결이 사라져도 기존 업무 메타·그룹·가이드·이력은 보존됩니다. 상단 그리드의 [저장] 바로 오른쪽에 있는 [서버 설정 불일치 건 일괄 삭제]는 미저장 변경이 없을 때 시작합니다.

1. 조회조건을 적용하고 정리 버튼을 누릅니다. 현재 페이지의 선택 행에 한정하지 않고 조회조건 전체의 확정 누락 항목을 미리 봅니다.
2. 참조가 남거나 참조·배포 안전성을 확인할 수 없으면 전체 정리를 차단합니다. 연결된 사용자나 카탈로그를 자동 삭제하지 않습니다.
3. 대상 전체와 새 사유를 확인하고 실행합니다. 대상이 없으면 [확인]은 비활성화됩니다. 미리보기는 5분간 유효하며 설정·권한·참조·버전이 바뀌면 다시 확인합니다.
4. 성공하면 현재 소유 구성만 정리하고 직전 이력과 원 결과는 보존합니다. 외부 데이터베이스의 업무 데이터를 삭제하지 않습니다.

## 6. 거부되거나 확인이 필요할 때

- 현재 권한이 없으면 조회·변경이 거부됩니다. 조회만 가능한 계정은 편집할 수 없습니다.
- 다른 관리자가 먼저 저장했다면 입력을 보존하고 최신 전체 구성과 비교합니다. 자동 병합하지 않습니다.
- 서버 설정 불일치·확인 필요는 정상 연결이나 SQL 실행 성공을 뜻하지 않습니다. 원천과 현재 검증이 필요한 변경은 전체 저장을 거부할 수 있습니다.
- 별도 변경 이력 메뉴와 실제 SQL 실행·실행 근거 기록은 후속 소유 기능에서 제공합니다. 현재 화면의 엑셀 다운로드는 현재 페이지 범위입니다.
