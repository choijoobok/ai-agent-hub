# 테이블 관계

> 같은 데이터소스 안의 두 테이블과 연결 컬럼을 등록하고 업무상 의미를 검수합니다.

**메뉴 위치** 연동 관리 › 테이블 관계

## 1. 먼저 알아 둘 것

데이터소스와 두 테이블의 카탈로그·컬럼을 먼저 등록합니다. 카탈로그 저장 권한이 있어야 관계를 바꿀 수 있습니다. 관계 등록은 상대 테이블의 데이터 열람 권한을 부여하지 않습니다.

## 2. 찾기

데이터소스 또는 관계명·객체명을 넣고 [조회]를 누릅니다. 관계를 선택하면 아래에 양쪽 컬럼과 연결 쌍이 표시됩니다. 카탈로그의 [테이블 관계 열기]로 이동하면 해당 테이블이 포함된 관계만 새 브라우저 탭에 열려 원 화면의 편집을 유지합니다.

[테이블 관계 화면](./mockup.html#main)

## 3. 하기

### 3-1. 관계 등록하기

1. [신규 관계]를 누르고 데이터소스를 고릅니다.
2. [테이블 선택]에서 왼쪽·오른쪽 테이블을 각각 검색하고 [입력 반영]합니다. 같은 테이블도 두 역할로 선택할 수 있습니다.
3. 관계명, 양쪽 역할, 관계 유형, 관계 설명을 입력합니다. 설명에는 연결 목적과 양쪽의 상대 행이 없을 수 있는지, 중복·집계 시 주의할 점을 적습니다.
4. 양쪽 컬럼을 하나씩 선택하고 [쌍 추가]를 누릅니다. 복합 키는 전체 컬럼을 연결하고 순서를 양의 정수로 정합니다.
5. [저장]에서 변경 사유를 입력합니다. 선택 관계와 같은 소유 테이블의 다른 편집 관계도 함께 저장됩니다. 다른 소유 테이블의 편집은 그대로 남습니다.

### 3-2. 고치거나 지우기

관계와 컬럼 쌍을 편집한 뒤 저장합니다. 테이블을 바꾸면 기존 쌍 초기화 확인이 나오며 취소하면 입력이 유지됩니다. 관계 삭제 표시를 취소하면 해당 관계와 컬럼 쌍이 저장된 원본으로 돌아갑니다.

### 3-3. 검수하기

같은 활성 자료형 코드의 컬럼만 연결할 수 있습니다. 여러 행이 한 행에 대응하는 관계는 한 행 쪽의 검수된 기본키 또는 유일키 전체 컬럼이 필요합니다. 일대일 관계는 양쪽 모두 필요합니다. 근거가 부족하면 저장되더라도 미검수로 남습니다. 현재 기본키는 카탈로그에서 검수할 수 있으며, 유일키는 이미 검수 완료로 등록된 정보만 근거로 사용합니다.

### 3-4. 연결 지식 확인하기

현재 [연관 지식]은 미연결 안내를 표시합니다. 실제 지식·예제 역조회와 SQL 작성·모델 이용은 후속 범위입니다. 빈 목록을 연결된 지식이 없다는 뜻으로 판단하지 않습니다.

## 4. 저장되지 않을 때

- 자료형이 다르거나 비활성·미등록이면 연결 컬럼과 공통코드를 확인합니다.
- 소유 테이블을 다른 사람이 바꿨으면 편집 내용을 확인한 뒤 다시 조회합니다. 자동으로 합치지 않습니다.
- 처리 결과를 확인할 수 없으면 [결과 확인]으로 원 저장의 결과를 확인합니다. 새 저장을 반복하지 않습니다.
- 저장 성공 뒤 재조회 실패 안내가 나오면 안내의 [조회]로 저장된 내용을 다시 불러옵니다.

## 5. 다른 메뉴와의 관계

데이터소스 관리와 스키마 카탈로그에서 등록한 객체를 이용합니다. 관계를 저장하면 소유 카탈로그의 변경 이력에 전체 구성이 함께 남습니다. 외부 테이블의 과거 판을 참조한 관계는 그 판의 컬럼을 계속 사용합니다.
