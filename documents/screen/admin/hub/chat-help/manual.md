# 채팅 도움말·주의사항

**메뉴 위치** AI Agent Hub 관리 › 업무 지식 관리 › 채팅 도움말·주의사항

사용 도움말, 새 대화 초기 안내, 개인정보·전송 주의사항의 본문을 각각 관리합니다.

[구분별 안내 콘텐츠 편집](./mockup.html#main)

## 1. 구분 선택과 조회

상단 **구분**에서 편집 대상을 선택합니다. 명칭 옆의 별표는 저장하지 않은 입력이 있다는 뜻입니다. 다른 구분을 선택했다 돌아와도 입력은 유지됩니다. **조회**는 선택한 구분만 다시 불러오며, 변경 중이라면 입력을 버릴지 먼저 확인합니다.

처음 설치된 안내는 미설정입니다. 예시 문구가 자동 등록되지 않으므로 실제 사용할 문구를 작성해야 합니다. 구분을 추가하거나 삭제하고 사용 중지하는 기능은 없습니다.

## 2. 본문 작성과 미리보기

1. **작성 형식**을 고르고 **본문**을 입력합니다. 형식을 바꿔도 원문은 변환되지 않습니다.
2. **본문 크게 편집**을 누르면 넓은 편집창이 열립니다. 오른쪽 아래 모서리를 끌어 크기를 조절합니다.
3. **반영**은 입력을 본문으로 옮깁니다. **취소**, 닫기, Esc는 확대창에서 바꾼 내용만 버립니다. 아직 서버에 저장하지 않습니다.
4. **미리보기**로 표시 결과를 확인합니다. 조회 전용 사용자도 이용할 수 있습니다.

마크다운은 제목·목록·표·코드·링크를, HTML은 허용된 표현을 표시합니다. TEXT는 입력한 문법을 그대로 보여 줍니다. 이미지·스크립트·위험한 링크나 스타일은 표시에서 제거되고 안내가 나옵니다. 원문은 유지됩니다.

## 3. 선택한 안내 저장

**저장**을 누르고 대상 구분과 적용 버전을 확인한 후 이번 변경 사유를 입력해 저장합니다. 선택한 구분만 저장하며 다른 구분의 미저장 입력은 유지합니다. 성공하면 적용 버전이 갱신됩니다. 동일 내용은 새 버전을 만들지 않습니다.

## 4. 저장되지 않을 때

- 본문이나 사유가 공백이거나, 위험 표현을 제거한 후 표시할 내용이 없으면 저장할 수 없습니다.
- 다른 관리자가 먼저 변경했다면 기존 내용을 덮어쓰지 않습니다. 입력을 확인한 뒤 해당 구분을 다시 조회합니다.
- 결과가 확인되지 않았다는 안내가 나오면 **저장 결과 확인·재전송**를 사용합니다. 확인될 때까지 입력 변경과 새 저장은 잠깁니다.
- 조회 전용 권한은 편집·저장이 잠깁니다. 본문은 최대20만 문자이며 과도한 표나 표시 크기도 제한합니다.

## 5. 다른 화면과의 관계

여기서 저장한 안내는 업무 지식·모델 지침과 별개입니다. 서로 자동 복사하거나 변경하지 않습니다. 저장자·시각·사유와 과거 전체 본문은 보존됩니다. 별도 이력 조회 화면과 실제 채팅의 안내 표시·제출 검증은 후속 기능에서 연결합니다. 현재 관리 화면의 저장만으로 채팅에 표시되거나 사용자 동의가 기록되지는 않습니다.
