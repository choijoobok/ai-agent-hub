# 지식 검색 태그·동의어

**메뉴 위치** AI Agent Hub 관리 › 업무 지식 관리 › 지식 검색 태그·동의어

[태그와 동의어 관리](./mockup.html#main)

## 1. 조회와 입력

검색 텍스트는 대표어와 동의어에서 함께 찾습니다. 태그 ID나 사용 여부로도 조회할 수 있습니다. 목록의 태그를 선택하면 하단 동의어와 연결 지식을 함께 확인합니다. 탭 전환만으로 다시 조회하지 않습니다.

**신규**로 태그를 추가하고 검색 텍스트를 입력합니다. 신규 사용 여부는 꺼짐입니다. 필요한 동의어와 설명은 하단에 입력합니다. 전각·앞뒤 공백·영문 대소문자만 다른 대표어는 중복으로 저장할 수 없습니다. 같은 태그의 대표어·동의어끼리도 중복을 허용하지 않습니다. 다른 태그에서 같은 동의어를 쓰는 것은 가능합니다.

## 2. 저장과 취소

변경 사유를 입력하고 **저장**합니다. 태그와 그 동의어 전체가 함께 저장되고 적용 버전이 올라갑니다. 독립 태그 행은 부분 성공을 유지하므로 실패 행의 입력을 확인해 다시 저장합니다. 미저장 변경이 있는 상태에서 다른 태그를 선택하거나 다시 조회하면 폐기 여부를 확인합니다. 취소하면 입력과 선택을 유지합니다. 행의 상태 컬럼에서 해당 행 변경을 되돌릴 수 있습니다.

저장 결과를 확인할 수 없으면 새 요청을 만들지 않고 입력을 잠급니다. **저장**을 다시 누르면 원 요청의 처리 결과를 확인한 뒤 필요할 때 같은 요청을 보냅니다.

## 3. 사용 여부와 연결 지식

사용 여부를 끄고 저장하면 다음 태그 후보에서 대표어와 동의어를 제외합니다. 정의·과거 이력·지식 연결은 보존됩니다. 태그 변경이 지식 본문이나 지식 버전을 바꾸지 않습니다.

연결 지식은 지식 ID·지식명·지식 리비전·매핑 활성 여부를 읽기 전용으로 표시합니다. 현재는 지식 연결 기능이 아직 연결되지 않았다는 안내가 나옵니다. 실제 지식 연결과 검색 적용은 후속 기능에서 검증합니다.

## 4. 삭제와 저장 실패

신규 미저장 행은 바로 제거할 수 있습니다. 조회된 태그는 선택해 상세를 확인해야 삭제 표시를 사용할 수 있습니다. 동의어가 있으면 먼저 동의어를 제거하고 저장합니다. 동의어와 지식 참조가 모두 없을 때 태그 삭제가 가능하며 기존 지식 링크를 자동 삭제하지 않습니다. 참조를 확인하지 못하면 삭제할 수 없습니다.

대표어·동의어는 원문200자 이내이며 정규화 후400자 이내입니다. 중복·낡은 버전·권한·참조 검사에 실패하면 저장되지 않습니다. 다른 관리자가 먼저 저장했다면 입력을 검토한 뒤 다시 조회합니다. 변경 전후 전체 정의와 변경자·시각·사유는 보존되며 별도 이력 조회 화면은 후속 기능입니다.
