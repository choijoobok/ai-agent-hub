# 요건 정의서 — 지식 검색 태그·동의어

## 개요

- **무엇을 하는 화면인가**: 고정 태그 ID별 최종 적용 검색 표현과 동의어를 관리하고 연결된 지식의 사용처를 확인한다.
- **프로세스상 위치**: 태그 정의 → 태그 직접 저장·이력 → 검색 표현 반영. 지식별 태그 ID 매핑은 SCR-011에서 독립 변경
- **이 데이터를 누가 쓰나**: 권한 있는 관리자와 연결 업무의 담당자가 현재 적용값 또는 업무 처리 근거로 사용한다.
- **바꾸면 어디가 흔들리나**: 소유 기능의 저장·권한·참조 및 이력/감사 연결을 함께 확인한다.

> 미구현 화면 초안이며 사용자 화면 합의·제품 구현·G3(설계 승인 게이트) 승인이 아니다. [화면 정본](../../../../spec/60-screens/_index.yaml)과 [기능 정본](../../../../spec/31-features/002-admin.yaml)을 따른다. 표시 예시는 실제 데이터·물리명·운영 기본값이 아니다.

## 1. 화면 구성

상단 조회조건 → 지식 검색 태그·동의어 목록 → 동의어 · 연결 지식 순서다. 제목·건수는 왼쪽, 작업 버튼은 상단·그리드 툴바·모달 하단에서 우측 정렬한다. 초기 화면의 모든 탭은 실제 전환하며 같은 상위 대상의 입력·선택·추가/제거 행을 유지한다.

관리 화면은 최종 적용본만 조회하고 변경 입력은 임시값으로 분리한다. 변경 권한을 부여받은 소수의 업무 전문가와 관리자만 소유 범위의 전체 구성을 직접 저장한다. 메뉴 표시뿐 아니라 서버가 저장 직전 현재 액션·대상 범위 권한, 자기 기준 리비전, 필수 참조와 기술 검증을 확인한다. 검증된 전체 변경과 변경 전후 이력·변경자·시각·사유는 같은 트랜잭션으로 반영한다. 일반 admin 계정이나 조회 권한만으로 변경할 수 없다. 별도 승인 요청·검토자/승인자 판정·전결/승인 사용 설정은 제공하지 않는다.

### 1-3. 마스터-디테일·이력 경계

- 선택 변경·조회·이탈 때 미저장 변경을 확인하고 취소하면 선택·입력을 보존한다. 결과 불명에는 새 명령 없이 원 처리 결과를 확인한다.
- SCR-047는 원 화면을 읽기 전용 상속한다. 변경 요약·이력 저장일시 범위만 추가하며 별도 이력 요건서/목업·이력 탭·복원 버튼을 만들지 않는다.
- 소유 구성의 전체 집합을 확보하며 미열람 탭을 누락 저장하지 않는다. 관측/사용처·외부 원천 상세는 저장에서 제외한다.

셀 편집은 [공통 그리드 표준](../../../../../aidd-guide/standard/frontend/grid.md)을 따른다. 현재 권한과 컬럼별 편집 조건을 만족하면 셀을 더블 클릭해 바로 입력하고, 저장 전까지는 로컬 변경으로 유지한다. 별도 수정 버튼은 두지 않는다.

행별 변경 취소는 [공통 그리드 표준](../../../../../aidd-guide/standard/frontend/grid.md)의 상태 컬럼 되돌리기를 사용한다. 툴바의 편집 취소 버튼은 두지 않는다.

### 3-2. 고정 조건 · 기본 정렬

- 항상 현재 메뉴·액션과 대상 열람 범위를 서버에서 검사한다. 최종 적용본만 표시한다.
- 기본 정렬·페이지 방식·조회 기간/상한·보존 기간·대량 반출 한도는 소유 계약 미정이다. 운영값을 추정하지 않는다.
- 빈 결과·권한 제외·조회 실패·미확인을 구분한다. 명령과 연계 조회의 권한을 자동 승계하지 않는다.

### 편집 가능 판단
