# 요건 정의서 — 월별 개인 쿼터 기준

## 개요

- **무엇을 하는 화면인가**: 기준년월별 금액·단가/환산율·보정·메모를 저장하고 등급 기준과 사용자 배정 결과를 조회한다. 등급별 배분·사용자 배정 두 탭만 제공하며 월말 배치가 다음 달 기준으로 최종 배분한다.
- **프로세스상 위치**: 쿼터 등급 관리·월별 단가 → 월 기준 저장 → 미래 예정 배분/재생성(선택) → 월말 자동 최종 배분 → 해당 월 적용
- **문서 범위**: 미구현 요건·목업 초안. 수치는 예시이며 제품 구현·물리/API 상세·G3 승인이 아니다.

## 1. 화면 구성

기준년월별 금액·단가/환산율·보정·메모를 저장하고 등급 기준과 사용자 배정 결과를 조회한다. 등급별 배분·사용자 배정 두 탭만 제공하며 월말 배치가 다음 달 기준으로 최종 배분한다. 제목·건수는 왼쪽, 작업 버튼은 각 그리드 상단 오른쪽이다. 모든 탭은 실제 전환하며 같은 대상의 입력·선택을 유지한다.

목록 연동: 기준년월
대상 편집 조건: 편집 가능=Y
선택 무관 버튼: 행 추가
저장 후 실행 버튼: 쿼터 배분 실행
산정 검증 버튼: 저장·쿼터 배분 실행
배분 유효성: 쿼터 배분 완료 여부=계획 가능 금액·월 환산율(계획 통화/USD)·보정률
행 추가 탭: 월별 개인 쿼터 기준 목록
행 제거 보호: 보존 사유
상태별 버튼: 허용 목록

## 6. 규칙 — 저장 · 실행

- 화면 식별/조회조건은 기준년월 하나다. 단가 원 기준 월/리비전·승계 원 기록은 비표시로 보존하고 별도 단가기준년월/환산근거 컬럼을 두지 않는다. 메모는 셀 위 textarea로 편집하고 필요한 환산/보정 설명과 원 처리 기록에 연결한다.
- 수동 행 추가는 동일 기준년월의 저장된 유효 SCR-016 단가가 있어야 한다. 없거나 미완료/조회 실패·월 중복이면 행을 만들지 않는다. 행 추가만으로 단가를 잠그지 않는다. 최초 저장과 단가 고정은 함께 성공/실패한다.
- 최초 단가 고정 때 현재 권한·자기 기준본·고정 요청 상한의 원 실적/보완을 재대조하고 차이는 비교·명시 재확인한다. 이후 금액/환산율/보정 재저장은 잠긴 USD 단가·원 스냅샷/상한을 바꾸지 않는다. 잠긴 단가 해제/교체·저장된 월 기준 삭제는 제공하지 않는다.
- 월별 화면은 해당 월 이하의 시작월 중 최신 쿼터 등급 기준 전체를 조회만 한다. 등급명/순위/가중치·등급 추가/제거/이전은 SCR-064에서 관리한다. 적용 기준이 없거나 사용자 등급 대응이 유효하지 않으면 임의 가중치/최저 등급으로 배분하지 않는다.
- 수동 쿼터 배분 실행은 대상 월 시작 전 저장본으로 예정 결과를 생성/재생성한다. 사용자 배정 탭이 이 결과를 조회한다. 재생성은 해당 월의 이전 예정 세트를 이력으로 보존하고 새 유효 세트로 교체하며 중복 가산하지 않는다. 미저장 입력으로 실행하지 않는다.
- 완료 여부 스위치는 조회 전용이다. 미래 월은 현재 기준에 유효한 예정본, 월 시작 후는 월말 최종 배치 완료를 뜻한다. 금액/환산율/보정·적용 등급 기준/효력 등급이 바뀌면 해당 예정본은 낡음으로 표시한다. 메모만 변경해도 예정 결과를 무효화하지는 않는다. 조회 실패/불명은 별도 확인 필요 상태다.
- 월말 스케줄 배치는 다음 달 M월 시작 경계를 마감으로 삼아 최신 저장된 M월 기준이 있으면 그 설정을 적용한다. M월 기준이 없으면 새 M월 행을 생성하고 바로 직전 월의 유효 금융기준(금액·원 USD/단가 참조·당시 환산율·수동 보정)을 그대로 복사한다. 조회 실패·잘못된 기존값은 없음으로 간주해 덮어쓰지 않는다. 직전 월 유효 기준도 없으면 임의 값을 생성하지 않는다.
- 월말 배분의 사용자·활성 효력·승인된 사용자 등급·등급 가중치는 두 경우 모두 M월 기준이다. 미승인 승급 신청이나 마감 뒤 승인을 앞당겨 반영하지 않는다. 미래 수동 예정본이 없거나 낡았어도 배치는 최신 저장 기준으로 최종 생성하며 수동 재생성을 선행 조건으로 강제하지 않는다.
- 마감 스냅샷과 배치 결과/수행자·시각을 보존하고 같은 M월 최종 배분 효과는 한 번만 적용한다. 실패 재처리는 같은 원 마감 스냅샷/원 작업의 복구이며 월 시작 후 현재 값으로 수동 재생성하는 기능이 아니다. 정확 스케줄·월 경계 경합/재시도 기술 계약은 후속이다.
- M월 시작 이후 전체 수동 재생성과 월 기준/당월 등급 변경은 금지한다. 신규 이용자 일할·배정 없는 재활성·0명 월 최초 활성 시 기준 산정·첫 사용 전 최초 등급 정정의 기존 자동 개별 배정은 별도 규칙으로 유지한다. 이미 배정한 다른 사용자의 한도를 다시 나누지 않는다.
- 활성0명이어도 월 기준/배치 준비 성공과 개인 배분 기준 미산정을 구분한다. 수동 보정/산정 처리 근거 탭은 없고 필요한 원 기록·배치/개인/월별 상세는 비용 관리 통계와 원 변경 이력에서 확인한다.
