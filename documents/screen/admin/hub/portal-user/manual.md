# Portal 이용자 관리

관리 콘솔의 **AI Agent Hub 관리 → 공통 기반 → Portal 이용자 관리**에서 업무 이용자를 관리합니다. 관리자 계정과 Portal 계정은 별개입니다.

## 1. 계정 등록과 조회

1. 사용자 아이디·이름·이용 상태 조건을 정하고 **조회**합니다.
2. 자체 인증 환경에서는 **행 추가** 후 아이디·이름·조직·사용 시작일을 입력합니다. 종료일을 비우면 무기한입니다.
3. 변경 사유를 입력하고 상단 **저장**을 누릅니다. 새 계정은 비활성이며 현재 최저 등급이 자동 부여됩니다. 유효한 현재 등급 기준이 없으면 등록할 수 없습니다.
4. 저장한 계정을 선택해 하단에서 그룹을 연결한 뒤 상단 이용 상태를 켜고 저장합니다. 로그인 잠금·비밀번호 변경 필요·변경일은 읽기 전용입니다. 저장된 계정의 아이디 변경이나 삭제는 제공하지 않습니다.

외부 인증 환경의 원천·주체는 검증된 원천과 대조합니다. 이름·조직·비밀번호를 관리자가 덮어쓰지 않습니다. 외부 연결이 준비되지 않으면 등록/이용을 허용하지 않습니다.

## 2. 사용자 그룹

하단 **사용자 그룹 → 행 추가**에서 그룹을 선택하고 메모·변경 사유를 입력해 저장합니다. 활성 여부를 꺼도 관계와 감사는 남습니다. 마지막 활성 그룹을 회수할 때는 **이용자도 함께 비활성화**를 켜야 합니다. 사용자 그룹 화면의 사용자 탭에서도 같은 소속을 관리합니다.

탭과 이용자를 왕복해도 입력은 보존됩니다. 다른 탭이나 화면에서 같은 이용자를 저장한 뒤에는 낡은 판을 덮어쓸 수 없습니다. 입력을 확인한 후 해당 탭을 다시 조회합니다.

## 3. 쿼터 등급과 추가 토큰

**쿼터 등급**에서 적용 월의 후보 기준을 조회하고 등급을 선택합니다. 당월은 배정 전 등급 정정만 허용하며 신규 예약·월 이동·예약 취소는 미래 월만 가능합니다. 변경 사유와 함께 저장합니다. 기준에서 빠지는 등급은 쿼터 등급 관리 화면의 명시적인 이전 대상으로 연결합니다.

배정 기능 연결 전에는 한도·사용량·잔여량을 `—`와 안내 문구로 표시합니다. 0이라는 뜻이 아닙니다. 일부 설치되었거나 상태 확인에 실패하면 등급 변경을 차단합니다. **추가 토큰**은 조회 전용입니다. 배정·신청/승인 생산 기능은 후속으로 연결합니다.

## 4. 대상별 아이디 매핑

데이터소스·대상 시스템 탭은 현재 조회 가능한 대상 후보를 표시합니다. 매핑을 켤 때 대상 사용자 아이디와 신원 연결 근거·변경 사유를 입력합니다. 변경한 행만 저장하고 다른 탭/미열람 매핑은 보존합니다. 대상 후보 연결 전에는 편집할 수 없습니다. 여기에는 외부 시스템 비밀번호나 호출용 토큰을 입력하지 않습니다.

## 5. 비밀번호 초기화와 잠금 해제

자체 계정을 선택하고 상단 변경 사유를 입력한 뒤 전용 명령을 사용합니다. 초기화된 임시 비밀번호는 최초 성공 응답에서 한 번만 표시됩니다. 화면을 닫거나 응답을 받지 못하면 다시 조회할 수 없으며, 결과 확인 뒤 필요한 경우 별도 초기화를 수행합니다. 같은 원 명령을 재시도해 비밀번호를 다시 발급하지 않습니다.

잠금 해제는 로그인 실패 잠금만 해제합니다. 이용 기간·그룹·비활성 상태를 바꾸지 않습니다. 실제 Portal 로그인과 최초 비밀번호 변경 화면은 별도 인증 기능에서 연결합니다.

## 6. 저장 실패와 이력

상단 여러 계정 중 일부만 실패하면 성공은 유지되고 실패 행만 남습니다. 하단은 선택 이용자의 변경 단위 전체가 함께 성공하거나 취소됩니다. 결과 미확정 안내가 나오면 입력을 유지한 채 다시 저장해 원 결과부터 확인합니다. 비밀번호를 제외한 전체 관리 구성·변경자·시각·사유와 이력을 원자적으로 보존합니다. 독립 이력 화면은 후속 기능입니다.
