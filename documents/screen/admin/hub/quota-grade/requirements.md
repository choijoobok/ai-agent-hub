# 요건 정의서 — 쿼터 등급 관리

## 개요

- **무엇을 하는 화면인가**: 시작월별 등급·순위·배분 가중치를 한 번 등록하고 변경 전까지 계속 적용한다. 상단은 기준 시작월·메모·등록자/등록일시, 하단은 해당 기준의 전체 등급이다.
- **프로세스상 위치**: 등급 기준 등록 → 월별 개인 쿼터 기준에서 적용 기준 조회 → 월말 배치의 다음 달 사용자 배분
- **문서 범위**: 미구현 요건·목업 초안. 수치는 예시이며 제품 구현·물리/API 상세·G3 승인이 아니다.

## 1. 화면 구성

시작월별 등급·순위·배분 가중치를 한 번 등록하고 변경 전까지 계속 적용한다. 상단은 기준 시작월·메모·등록자/등록일시, 하단은 해당 기준의 전체 등급이다. 제목·건수는 왼쪽, 작업 버튼은 각 그리드 상단 오른쪽이다. 하단 그리드가 하나이므로 탭 없이 가운데 스플리터 아래에 쿼터 등급 그리드를 직접 표시한다. 기준을 왕복해도 입력·선택을 유지한다.

목록 연동: 등급 기준 시작월
대상 편집 조건: 편집 가능=Y
선택 무관 버튼: 행 추가·기준 복사
행 추가 탭: 등급 기준·쿼터 등급
상태별 버튼: 허용 목록

## 6. 규칙 — 저장 · 실행

- 등급 기준은 시작월별 전체 등급 세트다. 대상 월 이하인 시작월 중 가장 최근 기준 하나를 사용하며 다음 기준 시작 전까지 계속 적용한다. 매월 복제/재등록하지 않는다. 적용 가능한 기준이 없으면 임의 기본 가중치로 배분하지 않는다.
- 새 기준은 미래 시작월로 작성하고 직전 기준의 전체 등급을 편집용으로 복사할 수 있다. 시작월은 저장 후 변경하지 않는다. 현재/과거에 적용된 기준은 수정/삭제하지 않고 변경은 새 미래 기준으로 등록한다.
- 등급은 안정 참조로 연결한다. 이름 변경이나 새 기준 복사가 사용자/승인/과거 배정의 참조를 새 이름 파싱으로 바꾸지 않는다. 신규 기본 등급은 해당 효력 월 기준의 최하위 등급이다.
- 배분율은 기존 상대 가중치다. 0보다 큰 수·소수 둘째 자리이며 순위가 높은 등급의 값은 낮은 등급 이상이다. 등급별 전체 풀의 백분율이나 합계100 조건을 만들지 않는다. 개인 기본 한도 산식은 REQ-116이 정본이다.
- 등급명·순위는 같은 기준 안에서 중복하지 않는다. 빈 세트/누락 가중치·순위 역전은 저장을 거부한다. 사용 중인 등급을 제거/통합할 때는 같은 미래 기준에 남는 이전 등급과 영향 대상을 확인하고 전체를 함께 저장한다. 등급 이전 효력은 해당 변경 기준 시작월 S부터이고 S 이전 월은 바꾸지 않는다. 원 승인/효력 이력은 수정하지 않고 별도 이전 근거를 남기며 후속 기준에서 대응 등급이 빠지면 보완 전 반영하지 않는다. 미래 기준 삭제 시 그 기준에서 파생한 미발효 이전 예약도 함께 대조하고 필요한 취소/대체 예약을 별도 이력으로 반영한다. 이미 발효한 사용자 등급/승인 이력은 삭제하지 않는다.
- 미래 기준의 수정/삭제는 그 시작월부터 다음 기준 직전월의 기준 영향과 이전된 사용자 효력 예약이 이어지는 후속 기준까지 검사한다. 해당 구간의 수동 예정 배분은 낡음으로 표시하고 월말 배치는 다음 달 유효 기준의 최신 저장본으로 최종 산정한다. 월 시작 후 실제 적용본을 변경하지 않는다.
- 등록자/등록일시는 최초 저장의 서버 기록이다. 메모는 기존 largeText 셀 위 textarea로 편집한다. 같은 기준의 메모와 등급 전체를 저장하며 등록 정보는 수정하지 않는다.
- 현재 권한·자기 기준본 충돌·전체 참조 유효성을 저장 시 다시 검사한다. 등급 변경으로 사용자 그룹/모델 선택 권한을 바꾸지 않는다. 변경 이력은 원 화면을 상속하는 별도 메뉴이며 독립 목업을 복제하지 않는다.
