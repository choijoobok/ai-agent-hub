# 쿼터 등급 관리

> 시작월별 등급·순위·상대 가중치를 한 세트로 관리합니다. 변경이 없는 달에는 기존 기준이 계속 적용됩니다.

## 1. 열기와 조회

**AI Agent Hub 관리 → 공통 기반 → 쿼터 등급 관리**에서 조회합니다. 상단 기준을 선택하면 하단에 전체 등급이 표시됩니다. 시작월 또는 등급명으로 검색할 수 있습니다. 현재/과거 기준은 읽기 전용입니다.

## 2. 새 기준과 복사

1. 상단에서 행을 추가하고 미래 시작월을 `YYYY-MM`으로 입력합니다.
2. 직전 기준을 이어 쓰려면 **직전 기준 복사**를 누릅니다. 최초 기준이면 하단에 등급을 직접 추가합니다.
3. 등급명·양의 순위·상대 가중치를 입력합니다. 같은 기준에서 이름/순위는 중복할 수 없고 높은 순위의 가중치는 낮은 순위 이상이어야 합니다. 가중치 합계를100으로 맞출 필요는 없습니다.
4. 변경 사유를 입력하고 상단 **저장**을 누릅니다. 메모와 하단 전체 등급이 함께 저장됩니다.

## 3. 수정·이동·삭제

미래 기준의 메모·등급을 수정할 수 있습니다. 시작월은 저장 후 변경할 수 없습니다. 등급의 이름을 바꾸거나 복사해도 안정 식별자는 유지됩니다. 기준 간 이동에는 각 편집본이 보존되며 상단 되돌리기는 해당 기준의 편집을 되돌립니다. 하단 조회나 다시 복사할 때 기존 편집이 있으면 폐기 여부를 확인합니다.

미저장 신규 기준은 즉시 제거됩니다. 조회한 기준은 상세 확인 후 미래 기준·외부 참조 없음이 확인된 때 삭제할 수 있습니다. 삭제할 때 직접 소유 등급 구성은 함께 제거되지만 안정 식별자와 전체 과거 이력은 남습니다. 기존 사용자/예약/배정 연결은 자동 삭제하지 않습니다.

## 4. 확인 불가 또는 저장 실패

- **사용자 등급·배정 기능 연결 전**이면 참조 사용자 수가 미확인으로 표시됩니다. 설치되지 않은 상태와 조회 실패를 구분합니다.
- **참조 원천을 확인할 수 없음**이면 저장/삭제를 중단하고 다시 조회합니다.
- 기준본 충돌은 다른 변경을 다시 조회해 반영합니다.
- 원 명령 결과가 미확정이면 내용을 유지하고 저장을 다시 눌러 결과를 확인합니다. 새 명령으로 중복 등록하지 않습니다.
- 여러 기준 중 일부만 실패하면 성공한 기준은 유지되고 실패한 행이 남습니다.

실제 사용자 등급 이전·예약과 월별 배정 연결은 후속 기능에서 제공됩니다. 현재 페이지의 표시 열은 엑셀로 내려받을 수 있습니다.

## 5. 변경 이력

저장 사유·관리자·서버 수락 시각과 부모/자식 전체 이력이 함께 기록됩니다. 독립 이력 조회 화면은 후속 공통 이력 화면에서 제공합니다.
