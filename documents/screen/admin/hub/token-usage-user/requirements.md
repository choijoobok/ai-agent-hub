# 요건 정의서 — 사용자별 토큰 사용 통계

## 개요

- **무엇을 하는 화면인가**: 사용자별 실제 토큰 사용·배정/잔여를 조회하고 선택 사용자의 월별 사용·용도/모델 구성·배정/배치 이력을 확인한다.
- **프로세스상 위치**: 월 기준/등급 기준·월말 배분·원 호출 기록 → 비용 관리 종합 → 월별/사용자별 상세 조회
- **문서 범위**: 미구현 요건·목업 초안. 수치는 예시이며 제품 구현·물리/API 상세·G3 승인이 아니다.

## 1. 화면 구성

사용자별 실제 토큰 사용·배정/잔여를 조회하고 선택 사용자의 월별 사용·용도/모델 구성·배정/배치 이력을 확인한다. 제목·건수는 왼쪽, 작업 버튼은 각 그리드 상단 오른쪽이다. 모든 탭은 실제 전환하며 같은 대상의 입력·선택을 유지한다.

## 3. 조회 — 테이블과 범위

물리명은 미정이다.
 논리 소유 집합은 FEAT-043의 기준/조회 기록이다. 새 테이블·조인·API를 이 문서에서 확정하지 않는다. 현재 메뉴/대상별 권한과 반출 범위를 각각 검사하며 실패·미상·0건을 구분한다. 원 명령/자기 기준본·안정 참조는 비표시로 보존한다.

## 6. 규칙 — 저장 · 실행

- 실제 사용량은 당시 용도·실제 공급 경로/모델/effort·계량 단위·사용자/시스템 귀속과 출처를 사용한다. 현재 모델 용도 지정이나 사용자 현재 등급으로 과거 기록을 덮어쓰지 않는다.
- 공급사 계량·Hub 추정·미상을 구분하고 입력/캐시·출력 포함 추론을 중복 가산하지 않는다. 실패/중단/재시도/대체 호출의 실제 소비와 동일 실행 누적 재수신 중복 제거는 NFR-010/016의 기존 규칙을 따른다.
- 일반 배정·월 시작 전 예정/재생성·월말 최종 배분·신규 일할·추가 승인·만료를 구분한다. 예정 배분의 여러 생성본을 중복 배정 합계로 더하지 않는다. 조회 기준 시각과 유효한 결과 한 세트의 출처를 남긴다.
- Portal 쿼터 사용과 관리자 시스템 운영/지식 재임베딩을 분리한다. 운영 사용량은 실제 합계에 포함하되 개인 Portal 한도에서 차감하지 않는다. 적용 대상이 아닌 한도/잔여는 해당 없음이며 미상/조회 실패를0으로 표시하지 않는다.
- 새 통계는 조회/반출만 제공한다. 원 호출·사용량·월 기준·단가·등급·승인·배정 결과를 직접 수정하거나 청구/회계 정산하지 않는다. 개별 호출의 예상 청구액을 새로 계산하지 않는다.
- 공급사 월 대조값과 수동 대조/보정 참고 근거의 작성은 기존 종합 토큰 사용량·대조 화면이 소유한다. 새 통계는 같은 정본을 조회하고 입력/집계를 중복 소유하지 않는다.
- 각 조회·상세 이동·반출은 현재 별도 메뉴/대상 권한과 마스킹을 검사한다. 개인 조회 화면이라는 이유로 본인/다른 사람/운영 계정의 범위를 추정해 확대하지 않는다.

## 8. 엑셀 · 데이터 전제

- 반출은 현재 별도 EXPORT 권한과 허용 표시 열/범위만 적용한다. 숨은 제어값·비밀값은 반출하지 않는다. 업로드는 없다.
- 원 기록/단가/등급/승인/배정/사용량의 정본을 복제하지 않는다. 시드·제품 소스를 이번 작업에서 변경하지 않는다.
