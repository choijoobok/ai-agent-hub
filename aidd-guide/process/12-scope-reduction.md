# 절차 축소 3분류 — 줄일 수 있는 것과 안 되는 것

> **왜 절차가 무거운가는 [verification-cost.md](11-verification-cost.md) 가 갖는다** —
> DORA J-커브와 verification tax. 여기는 **"줄이자" 는 요구에 어떻게 답하는가** 하나다.
>
> **이 문서만 따로 있는 이유**: `AGENTS.md` §5-12 가 여기를 직접 가리킨다. 요구가 들어오는
> 순간 읽혀야 하는 문서이므로, 긴 문서의 한 절로 두면 그 링크가 중간을 가리키게 되고
> **중간을 가리키는 링크는 읽히지 않는다.**


사용자가 "너무 오래 걸린다, 절차를 줄이자"고 할 때 **AI가 즉답할 수 있어야 한다.**
그때 즉흥적으로 판단하면 반드시 지켜야 할 것부터 깎인다.

## 1. 줄일 수 있는 것 (결정은 `charter.expectations.reduced_scope` 기록)

| 항목 | 줄이는 방법 | 잃는 것 |
|---|---|---|
| 시퀀스 다이어그램 | 핵심 3개만 | 복잡한 흐름의 리뷰 난이도 상승 |
| 상세 유즈케이스 | 요약형(기본흐름+예외만) | 대안 흐름 누락 위험 |
| 자동 변이·전 규칙 수동 반전 | 중요 반례가 기본, 검증 공백에만 집중 반전 | 전수 변이 점수 없음. 기본 검증은 `quality/test-design.md` §0 |
| 반복 전체·실환경 시험 | 변경 영향 시험과 필요한 최종 회귀 한 번 | 비영향 결과 재사용 근거를 남겨야 함 |
| NFR 측정 항목 | 핵심 3개만 실측 | 나머지는 추정치로 인수 |
| 문서 생성 범위 | 요건정의서를 영역 단위로 통합 | 개별 기능 조회성 저하 |
| 게이트 병합 | G0+G1, G5+G6 (Lite 트랙) | 중간 점검 기회 감소 |
| 시나리오 테스트 | 핵심 프로세스만 | 액터 전환 버그 발견 지연 |

## 2. 절대 줄이면 안 되는 것

| 항목 | 이유 |
|---|---|
| **변경된 중요한 위험의 반례** | 인증 우회·데이터 손실·중복 실행을 실제로 차단하는지 확인해야 한다. 모든 규칙의 반전은 선택이다 |
| **권한 테스트** | 화면 숨김만으로는 못 막는다. API 직접 호출 검증 필수 |
| **중요 예외 흐름 TC** | 실제 변경에 해당하는 치명적 실패를 빠뜨리면 안 된다. 경미한 예외 조합 전수화는 하지 않는다 |
| **게이트 사용자 승인** | 없애면 나중에 "이런 줄 몰랐다"의 비용이 훨씬 크다 |
| **파괴적 명령 가드** | 2026년 실제 사고 유형. 되돌릴 수 없다 |
| **quality-check.mjs (중복·예외삼킴)** | 몇 초 걸린다. 줄일 이유가 없다 |
| **결정 카드 + 역질문** | 이걸 없애는 순간 게이트가 책임 이전 장치가 된다 |

## 3. 자주 줄이자고 하지만 줄이면 안 되는 것

| 항목 | 당장의 이득 | 나중의 비용 |
|---|---|---|
| **추적성 ID 연결** | 문서 작성이 빨라짐 | 2차 개발 때 "이 코드 왜 있지"에 답할 수 없어 손을 못 댄다 |
| **ADR 대안 2개** | ADR 작성이 빨라짐 | 결정을 뒤집을 때 근거가 없어 처음부터 다시 검토 |
| **가정 원장(ASM)** | 진행이 매끄러움 | 틀린 가정이 언제 들어왔는지 못 찾는다 |
| **TEST-FIRST** | 구현이 빨라 보임 | AI가 자기 코드에 맞춘 테스트를 쓴다 = 검증이 아니라 자기 확인 |

## 4. 응답 형식 — 세 분류를 그대로 낸다

```markdown
절차를 줄이자는 말씀으로 이해했습니다. 세 가지로 나눠 답변드립니다.

**바로 줄일 수 있는 것** (실제 시간 근거 없이는 단축률을 추정하지 않는다)
- 시퀀스 다이어그램: 남은 8개 → 핵심 2개만
- NFR 실측: 9개 → 핵심 3개 (나머지는 추정치로 인수, 리스크 기록)

**줄이면 안 되는 것** (줄이면 프로덕션에서 되돌려받습니다)
- 변경된 중요한 위험의 반례 — 권한 우회, 데이터 손실, 중복 실행 등
- 실제 DB 변경의 적용·복구, 연결 계약 변경의 대표 실환경 시험

**지금은 빠르지만 나중에 비싼 것** (판단은 하셔야 합니다)
- 추적성 연결 — 이후 변경 영향과 검증 범위를 찾기 어려워집니다

이미 승인된 간소화는 바로 적용하고, 추가로 필요한 결정만 묻습니다. 결정은 `charter.expectations.reduced_scope` 에 남깁니다.
```
